## Repositorios públicos

- [codectl](https://github.com/pgm095/codectl): CLI local que indexa un repositorio en SQLite con Tree-sitter y responde quién llama a qué, qué se rompe si algo cambia y qué archivos importan.
- [intake-pipeline](https://github.com/pgm095/intake-pipeline): ingesta de notas y medios con transcripción local, comparación con una base de conocimiento propia y cola de revisión humana antes de escribir nada.
- [printables-cli](https://github.com/pgm095/printables-cli): cliente no oficial en Python para listar, descargar, publicar y actualizar tus propios modelos en Printables.
- [ranking-pareado](https://github.com/pgm095/ranking-pareado): ordena imágenes o vídeos por comparaciones de a pares, en el navegador y sin dependencias.
- [quickkeys-ha](https://github.com/pgm095/quickkeys-ha): usa un mando Xencelabs Quick Keys como controlador físico de Home Assistant desde Linux.
